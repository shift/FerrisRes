## Scope and limits

This is a **broad first-pass source and test audit**, not an exhaustive line-by-line or formal audit of every module.

Direct source review covered the GPU generators, KV cache/compaction, model dispatcher and standard-transformer execution, CPU BlockAttnRes summaries, autodiff backward kernels, Adam/cross-entropy parameter plumbing, CPU training forward and CLI distillation backward, HTTP parser/server/CLI handlers, Armor integration, host tools, and selected safetensors/GGUF input validation. Existing tests provide additional coverage, but passing a module's tests is not equivalent to reviewing that module.

Not exhaustively validated: full pretrained checkpoint/reference parity; complete numerical gradients for every operation; multimodal heads/encoders; cognitive/robotics/trading paths; distributed networking and multi-GPU behavior; specialized optimizers and adapter persistence under long training; fuzzing of all file formats; concurrency/race/soak tests; Metal/DX12/WebGPU backends. GPU evidence here is from the available local wgpu backend, not all hardware.

Generic parallel reviewer dispatch returned process success but produced no review artifacts or task progress. Findings were therefore gathered and checked locally, not represented as independent peer-reviewed results.

## Evidence and remediation criteria

### A01 — Preserve causality in CPU BlockAttnRes summaries

- **Severity:** critical. **Task:** `1f821f56-be94-4e67-9176-8bb665be0236`
- **Location:** `src/model/cpu_block_attn_res.rs:640-710,1555-1610; src/training/backward.rs:57-61,230-237`
- **Evidence / trigger:** Reproduced: changing only second token flips first-token logit from +0.54119587 to -0.54119587 in forward and forward_train. Full-sequence mean summaries are broadcast to every token.
- **Acceptance:** Use per-token causal depth summaries; add prefix-invariance and prefill/decode equivalence tests. See cpu_forward_prefix_logits_are_causal and cpu_training_prefix_logits_are_causal.

### A02 — Repair GPU optimizer and autodiff parameter bindings

- **Severity:** critical. **Task:** `65ad0745-5902-4b43-bb29-b6a12096cd27`
- **Location:** `src/training/optimizer.rs:27,62,423-425,492; src/autodiff/backward.rs:19,47,74,120,160`
- **Evidence / trigger:** Reproduced cross entropy validation: set_immediates size16 exceeds pipeline immediate_size0. WGSL parameters are private zero-initialized variables, not uniform/immediate bindings. Same pattern exists in Adam and autodiff shaders; those variants source-verified only.
- **Acceptance:** Wire parameters consistently through supported bindings, configure pipeline ranges, then verify cross entropy, Adam, and backward numerically. See gpu_cross_entropy_dispatch_is_valid.

### A03 — Upload trained weights in AnyModel file loaders

- **Severity:** critical. **Task:** `95b2091a-4955-466a-bca0-be613d300647`
- **Location:** `src/model/dispatcher.rs:184-228`
- **Evidence / trigger:** Source-verified: from_safetensors/from_gguf only infer configuration then invoke constructors; parsed tensor values never enter created model. Does not implicate separate CPU Gemma loaders.
- **Acceptance:** Validate/map/upload all tensors and compare outputs against a reference checkpoint; missing required weights must error.

### A04 — Enforce Armor when enabled on API server

- **Severity:** critical. **Task:** `e10937fe-2879-4075-89a7-3f9615561585`
- **Location:** `src/main.rs:2468-2472,2495-2610`
- **Evidence / trigger:** Source-verified: serve stores armor in unused _armor field; neither completion handler performs input checks or output sanitization. --armor gives false assurance.
- **Acceptance:** Wire Armor checks into server generation or reject unsupported flag; test blocked input and redacted output through HTTP.

### A05 — Bound HTTP input and enforce connection deadlines

- **Severity:** high. **Task:** `a80d4d37-2b6d-4960-906f-2b5329ca16a7`
- **Location:** `src/server/mod.rs:166-194,249-258`
- **Evidence / trigger:** Source-verified: serial accept loop, unbounded read_line and Content-Length allocation, no read timeout. One idle client blocks all service; huge declared body can exhaust memory. No destructive/OOM probe performed.
- **Acceptance:** Limit headers/body, validate framing and reject over-limit lengths before allocation, enforce deadlines and bounded concurrency. Test slow/incomplete requests safely.

### A06 — Replace substring API request parsing with validated JSON

- **Severity:** high. **Task:** `e4cf60c3-46da-4ca1-baf4-a8d1f1710bea`
- **Location:** `src/server/mod.rs:324-359,400-455`
- **Evidence / trigger:** Source-verified: parsers always return Some, messages require literal {"role", strings stop at escaped quotes, stream detection requires exact "stream":true. Valid whitespace/key reordering changes meaning and malformed input is accepted.
- **Acceptance:** Use serde request types and range/schema validation; test pretty JSON, reordered keys, escaped content, malformed bodies and streaming booleans.

### A07 — Reject incomplete HTTP bodies instead of zero padding

- **Severity:** medium. **Task:** `f2bad3db-5284-4dd3-b931-8d7e15f09a6b`
- **Location:** `src/server/mod.rs:192-197`
- **Evidence / trigger:** Reproduced: declares Content-Length5, sends abc and closes write side; parser returns Some with zero-padded body because read_exact error is ignored.
- **Acceptance:** Propagate read failures and return 400; see truncated_http_body_is_rejected.

### A08 — Serialize all API response fields with JSON escaping

- **Severity:** medium. **Task:** `116fd67e-7e61-4c5a-b699-007c6b71e481`
- **Location:** `src/server/mod.rs:106-137`
- **Evidence / trigger:** Reproduced: assistant content containing U+0001 produces invalid JSON. Other string fields such as model/id/role are interpolated without escaping.
- **Acceptance:** Serialize structured responses with serde_json; test control characters and quoted model names. See response_with_control_character_is_valid_json.

### A09 — Implement OpenAI-compatible completion and SSE response schemas

- **Severity:** medium. **Task:** `b55ec85c-df4a-4289-966a-f3f571506717`
- **Location:** `src/server/mod.rs:296-314,383-391; src/main.rs:2566-2600`
- **Evidence / trigger:** Source-verified: stream=true computes complete response before returning one full-response SSE event, not chat.completion.chunk delta events. Text completion choices use message instead of text.
- **Acceptance:** Separate text/chat response types, emit real incremental SSE chunks and correct finish reasons; test with an OpenAI client.

### A10 — Enforce host shell timeouts and bounded output capture

- **Severity:** high. **Task:** `23d77210-e8cb-44e8-97ec-25babebf281d`
- **Location:** `src/inference/host_tools.rs:196-231`
- **Evidence / trigger:** Reproduced: sleep2 with timeout_secs1 completes successfully. Timeout variable unused; Command::output buffers all output before truncation. Post-hoc truncation can also split UTF-8.
- **Acceptance:** Use supervised child/process-group deadlines and bounded concurrent stdout/stderr reads; see shell_timeout_is_enforced.

### A11 — Enforce web_fetch max_bytes during response reads

- **Severity:** high. **Task:** `1ae1d9a8-1d8d-4dfd-90df-aed3135fc5d4`
- **Location:** `src/inference/host_tools.rs:115-119`
- **Evidence / trigger:** Reproduced with local HTTP fixture: 6-byte response returned despite max_bytes1; _max_bytes unused and entire body read into memory.
- **Acceptance:** Read through a bounded reader with explicit truncation/error semantics, including decompressed data; see web_fetch_obeys_byte_limit.

### A12 — Make file_read bounded and UTF-8-safe

- **Severity:** high. **Task:** `928be780-2290-40fe-a05c-4f66bea0b6c7`
- **Location:** `src/inference/host_tools.rs:150-156`
- **Evidence / trigger:** Reproduced: reading é with max_bytes1 panics at byte index1. Entire file is read before applying limit, so max_bytes does not bound memory.
- **Acceptance:** Bound reads before allocation growth and truncate only at valid character boundaries; see file_read_unicode_limit_does_not_panic.

### A13 — Correct autoregressive decode RoPE position off-by-one

- **Severity:** high. **Task:** `a324c6d7-347b-4819-91d2-a8669871dd80`
- **Location:** `src/inference/generator.rs:307,481; src/inference/unified_generator.rs:268,433; src/model/standard_transformer.rs:410-414`
- **Evidence / trigger:** Source-verified: first sampled token follows prompt positions0..N-1 and must use positionN, but both generators pass N+1. Layer uses supplied effective_pos directly.
- **Acceptance:** Use zero-based N+step and test cached logits against full-forward prefix logits, including context-extension modes.

### A14 — Honor zero output-token limits in GPU generators

- **Severity:** medium. **Task:** `6ff235b1-7f5e-42e2-bcbe-6e5e47a0a773`
- **Location:** `src/inference/generator.rs:294-306; src/inference/unified_generator.rs:257-267,342-432`
- **Evidence / trigger:** Source-verified: first token sampled/appended before max_tokens check, so nonempty prompt with max_tokens0 still produces one token. Audit streaming max_new_tokens0 too.
- **Acceptance:** Return empty output before prefill for zero budget; test buffered and streaming APIs.

### A15 — Use cache-local indices for repeated context compaction

- **Severity:** high. **Task:** `7fc711da-647c-4c3b-95ab-fa15caa87e28`
- **Location:** `src/inference/unified_generator.rs:272-292,432-434; src/inference/kv_cache.rs:157-200`
- **Evidence / trigger:** Source-verified: compaction selects indices from growing global_pos even after physical cache shrinks, and triggers every later step; eventually copies beyond physical capacity. Streaming decode lacks equivalent compaction.
- **Acceptance:** Separate absolute RoPE positions from current physical cache indices, validate every index, and test multiple capacity crossings and streaming parity.

### A16 — Infer attention heads from metadata rather than square projection width

- **Severity:** high. **Task:** `a8800f37-3493-4c7d-bc38-1ce8fa936ef9`
- **Location:** `src/model/dispatcher.rs:405-417`
- **Evidence / trigger:** Source-verified: for square 4096x4096 q_proj, infer_num_heads returns4096, implying head_dim1. Projection shape alone cannot determine head count.
- **Acceptance:** Load architecture config/head metadata and reject ambiguity; test LLaMA-style square Q projection and GQA.

### A17 — Implement architecture-correct standard-transformer gated FFN

- **Severity:** high. **Task:** `e67822f4-dba7-4de7-ad01-9794dd3cf968`
- **Location:** `src/model/standard_transformer.rs:325-326,464-465`
- **Evidence / trigger:** Source-verified: prefill/decode use ReLU(gate)+up, not SiLU(gate)*up required for supported LLaMA/Mistral SwiGLU. Other advertised families require their own activation.
- **Acceptance:** Represent architecture-specific activation/gating and compare per-layer outputs to reference models.

### A18 — Correct autodiff matmul gradient layouts and dispatch coverage

- **Severity:** high. **Task:** `cc500f88-5288-461c-aa96-b73c94a6e508`
- **Location:** `src/autodiff/backward.rs:8-60,506-552`
- **Evidence / trigger:** Source-verified: kernels index B/A as transposed but dispatcher binds original buffers. workgroup_size64 is 1D while Y dispatch is divided by64, so columns are under-covered even after parameter binding repair.
- **Acceptance:** Correct row-major transpose indexing and 2D coverage; use non-square finite-difference gradient checks after A02.

### A19 — Accumulate gradients for every reverse-mode graph edge

- **Severity:** high. **Task:** `e5f98e40-47e0-40ad-8fa1-985b3b4d63ea`
- **Location:** `src/autodiff/backward.rs:99-104,638-656; src/autodiff/graph.rs`
- **Evidence / trigger:** Source-verified: ReLU/softmax/matmul write directly to input gradients while Add/Scale accumulate; multiple consumers overwrite earlier contributions.
- **Acceptance:** Accumulate all contributions using safe temporary buffers or ordered addition; test x feeding two ReLUs and a diamond graph, after A02.

### A20 — Correct RMSNorm autodiff Jacobian and preserve epsilon

- **Severity:** high. **Task:** `c9a3b3e1-6ea9-4e67-affb-0c66b4bda549`
- **Location:** `src/autodiff/backward.rs:133-144,660-702`
- **Evidence / trigger:** Source-verified: unit-scale formula is inv_rms/d*(g-y*dot(g,y)) rather than inv_rms*(g-y*dot(g,y)/d); dispatcher discards NodeKind epsilon and sends1e-5.
- **Acceptance:** Implement correct normalization/weight derivatives and use node epsilon; verify numerical gradients for multiple rows and non-default epsilon after A02.

### A21 — Replace CLI distillation surrogate gradients with valid chain-rule backprop

- **Severity:** high. **Task:** `f37aa4d4-dc19-463d-b9fd-b90d10756d9e`
- **Location:** `src/main.rs:1933-2035`
- **Evidence / trigger:** Source-verified: immutable d_hidden= d_logits@lm_head^T is reused unchanged across all layers and substituted/truncated for Q/K/V gradients, omitting attention and normalization Jacobians. Freezing base weights does not justify omission.
- **Acceptance:** Backpropagate through frozen operations to trainable adapters, validate end-to-end finite differences, or explicitly expose approximation as a separate experimental mode.

### A22 — Honor API generation settings and model stop tokens

- **Severity:** high. **Task:** `22fa4eda-9e41-40b7-b9aa-045c2fd5fa82`
- **Location:** `src/main.rs:2515-2518,2570-2574`
- **Evidence / trigger:** Source-verified: chat uses hardcoded256 tokens and temperature0.7; text ignores requested temperature; both pass EOS=None, chat ignores top_p and always reports stop.
- **Acceptance:** Pass validated request configuration and model EOS through generation; test max_tokens0/1, greedy temperature, top_p and finish_reason.

### A23 — Decode API outputs with the loaded tokenizer

- **Severity:** high. **Task:** `d99b9a99-6fd8-4bf5-96e9-4c54cd7a3b9b`
- **Location:** `src/main.rs:2423-2440,2517-2519,2573-2575`
- **Evidence / trigger:** Source-verified: HF tokenizer is retained only as encoding closure, while output IDs are decoded using SimpleTokenizer. Real model vocab IDs yield corrupt output.
- **Acceptance:** Retain encode/decode tokenizer pair and stop silently falling back to incompatible tokenization for loaded models; test HF roundtrip and generated vocabulary IDs.

### A24 — Reject zero or invalid GGUF alignment without panicking

- **Severity:** high. **Task:** `a81fd196-dacf-4300-bfcd-409c93262645`
- **Location:** `src/model/gguf.rs:752-760,784-785`
- **Evidence / trigger:** Reproduced: tiny GGUFv3 file with general.alignment UInt32=0 panics at gguf.rs:785: attempt to divide by zero. See gguf_zero_alignment_returns_error_without_panic.
- **Acceptance:** Validate nonzero supported alignment and checked offset arithmetic; add tiny malformed metadata fixture and fuzz loader.

### A25 — Reject or handle empty prompts in CPU server generation

- **Severity:** high. **Task:** `b6e0143e-a804-4d34-936c-73eade53746d`
- **Location:** `src/main.rs:2635-2653; src/server/mod.rs:345-359`
- **Evidence / trigger:** Source-verified: empty prompt yields empty token vector with SimpleTokenizer; generate_cpu computes (all_tokens.len()-1)*vocab_size, underflow/index panic. Server JSON parser permits missing/empty prompt and handles requests serially without panic isolation.
- **Acceptance:** Validate nonempty token input or add BOS token, reject invalid requests, and test empty completions with loaded model.

## Recommended repair order

1. **Stop false security assurance:** A04, then A05/A06/A10–A12 before exposing server/tools to untrusted inputs.
2. **Restore mathematical correctness:** A01 and A02, then A18–A21. A18–A20 explicitly depend on A02 in engram.
3. **Restore real model behavior:** A03, A16/A17, A23; compare known checkpoint outputs against a trusted reference.
4. **Fix generation contracts:** A13–A15, A22/A25, initial RAG/tool tasks, then API schema/serialization and documentation.
5. Rerun targeted regressions, full suite, reference-model parity and long-context/long-training tests before claiming readiness.

Remaining validation limitations above should be included in any release decision. This report does not certify unaffected modules as bug-free.
